## 📋 نبذة عن المشروع | About the Project

Sahilha هو منصة ويب حديثة وسهلة الاستخدام، مصممة خصيصاً لطلاب جامعة أم القرى (UQU) لتسهيل وتحسين عادات الدراسة والتنظيم الأكاديمي.

Sahilha is an intuitive, student-centric web platform designed specifically for Umm Al-Qura University (UQU) students to streamline their study habits and academic organization.

---

## ✨ المميزات الرئيسية | Key Features

- 📚 **إدارة المقررات الدراسية** - Manage your courses easily
- 📝 **تنظيم المهام والواجبات** - Organize assignments and tasks
- 📅 **جدولة الاختبارات** - Schedule and track exams
- 🎯 **متابعة التقدم الأكاديمي** - Monitor your academic progress
- 📊 **تحليلات الأداء** - Performance analytics and insights
- 🔔 **إشعارات وتنبيهات** - Smart notifications and reminders
- 🌍 **واجهة ثنائية اللغة** - Bilingual interface (Arabic & English)

## 🚀 البدء السريع | Quick Start

### المتطلبات | Requirements
- Node.js v14 or higher
- npm or yarn
- Git

### التثبيت | Installation

```bash
# Clone the repository
git clone https://github.com/faris-15/Sahilha-.git

# Navigate to project directory
cd Sahilha-

# Install dependencies
npm install

# Start the development server
npm start
```
